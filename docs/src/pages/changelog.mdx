## `0.1.0-alpha.1` — 2026-11-25 (November 2026 Overhaul)

### Performance & benchmarks

- **Incremental Smithers benchmark DAG (`#867`, `78dbd431`):** Added 16
  `ReleaseFast` suites (13 standalone subsystem microbenchmarks + full-EVM
  opcode, contract, and precompile suites) with committed `bench/baseline.json`
  and `smthrs test //bench:report`.
- **Hot-path engine overhaul (`815ab72f`, `78dbd431`):**
  - `contract/snailtracer` (Prague) improved to **42.95 ms (5.48 Ggas/s)** from
    206.8 ms / 1.15 Ggas/s.
  - **4.63x** geomean speedup vs `maint/unified-v2` (**7.46x** vs original
    baseline) across the Osaka suite with 0 gas mismatches.
  - **90.85x–153.66x** ECRECOVER speedup (`std.crypto.ecc.Secp256k1` +
    pseudo-Mersenne + Jacobian + Shamir), Knuth Algorithm D 256-bit division,
    adaptive Montgomery MODEXP with 4-bit sliding windows and even-modulus CRT,
    and BN254 multi-Miller loop + GLV G1 mul.
  - **6.92x** faster database snapshots/reverts via O(1) append-only undo-log
    checkpoints and lazy O(1) `get_original_storage_indexed`.
  - **31.78x** faster EIP-7623 calldata token counting (32-byte SIMD) and
    **36.01x** faster O(1) `is_eip_active`.
  - Removed per-call 64 MiB OS thread spawn for shallow calls, added bounded
    per-`Evm` dispatch schedule caching, single-pass `packed_bitmap` jump
    tables, and sparse-reset FastLZ for OP Stack (`5.78x` on 68 B).
- **Opt-in native ARM64 JIT (`src/jit/`, `src/jit_bridge.zig`):** Added a
  zero-dependency AArch64 direct bytecode compiler with bounded LRU `JitCache`
  and exact interpreter replay on exceptional halts, opt-in via
  `EvmConfig.enable_native_jit = true` (default `false`). See
  [Benchmarks and native JIT](/guides/benchmarks-and-jit).

### Protocol & consensus

- **Prague & Osaka EIPs (`9af066f2`, `815ab72f`):** Completed Prague/Osaka
  support including `CLZ` (EIP-7939), `P256VERIFY` (EIP-7951), EIP-2537
  BLS12-381 precompile addresses, EIP-2935 historical block hashes, EIP-7623,
  EIP-7702 delegation, and Osaka transaction/code/ModExp limits (EIP-7823,
  EIP-7825, EIP-7883, EIP-7934).
- **Spec & state fixes (`7501b986`, `57e7d712`, `a44a34f1`, release-prep):**
  - Cut `zig build specs` failures from 1,031 → 581 → **38** (**2,213 / 2,251 passing = 98.31%**, with **100% of checked-in `eest/prague` passing**).
  - Fixed `CALL`/`CALLCODE`/`DELEGATECALL`/`STATICCALL` (`#842`), `LOG`/`RETURN`/`REVERT`/`CODECOPY`/`KECCAK256` bounds & zero-length handling, `CREATE`/`CREATE2` constructor `caller`/`value`, EIP-214 static-context checks, EIP-161 initial nonce, EIP-211/140 revert return data, Yellow Paper depth-1024 off-by-one, `SELFDESTRUCT` EIP-2929/150/6780 gas & end-of-tx cleanup, and Yellow Paper §9.4.1 right-zero-padding for truncated `PUSH1`–`PUSH32`.
  - Refactored `static_wrappers` into comptime `DatabaseProxy` (`.pass_through`,
    `.static`, `.lru`) and fixed canonical RLP account encoding in `database.zig`.
  - Unified `FrameCheckpoint` and `revertFrame()` rollback across logs, refunds,
    access lists, self-destructs, created contracts, and failed precompile value
    transfers.
  - Replaced hardcoded EVM gas and limit literals with named constants
    (`src/limits.zig`, `#843`) and removed non-platform-guard `SkipZigTest` stubs (`#696`).

### Testing, verification & tooling

- **Official EEST state test runner (`specs/eest_runner.zig`):** Added
  `zig build state-tests` and `scripts/fetch-eest-fixtures.sh` to run official
  pre-filled `ethereum/execution-specs` state tests (Frontier through Osaka)
  with full MPT state-root and RLP logs-hash verification. See
  [Project status](/status).
- **Formal verification (`zig build verify`):** Added LLVM 20 IR equivalence
  and UB-freedom checks, Bitwuzla/Z3 SMT-LIB2 proofs, and Lean 4 proofs under
  `verify/`.
- **Build & CI reliability (`c76088fa`, `8aa6216a`, `fe945ea7`):**
  - Fixed fresh-clone Voltaire `libcrypto_wrappers.a` archive production
    (`#862`, `#863`) and Linux `libunwind` linkage (`#815`).
  - Added automatic macOS Xcode SDK probing in CI for Zig 0.15.2 on `macos-26`
    runners.
  - Removed 22 unreferenced legacy Zig files and dead build steps.

### SDKs, publishing & documentation

- **C ABI & `@tevm/guillotine` Bun FFI SDK:** Shipped the native C ABI
  (`sdks/c/include/guillotine.h`, `src/evm_c_api.zig`) and Bun FFI TypeScript
  package (`sdks/typescript/`, Bun ≥ 1.1), removing the stale WASM backend.
- **Automated release pipeline:** Added `.github/workflows/release.yml`
  (cross-platform `darwin-arm64` + `linux-x64` native builds, `@tevm/guillotine`
  npm publish with provenance, and GitHub Releases with C FFI tarballs and
  `SHA256SUMS.txt`) and `scripts/release.sh`. See
  [Publishing and releases](/guides/publishing).
- **Documentation site (`guillotine.tevm.sh`):** Audited all Vocs 2 pages
  against `main` (`4ddc140b`) and added guides for benchmarks & native JIT,
  publishing & releases, and this changelog.
