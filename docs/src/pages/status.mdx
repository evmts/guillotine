# Project status

Guillotine is in **beta**, preparing for production release.

This page records the measured results for v0.1.0. Each number names its
source. The runs used Linux x86_64 and stock Zig 0.17.1 with native
`preserve_none` tail-call dispatch; no compiler fork is required.

## Ethereum spec compliance

### EEST state tests: 66,652 / 66,652 (100.00%)

`zig build state-tests` runs the official pre-filled Ethereum Execution Spec
Tests against the `src/` engine. Fixtures are `tests@v21.0.3`, pinned by release
tag and SHA-256 in `scripts/fetch-eest-fixtures.sh`.

| Run | Cases | Passed | Failed |
| --- | ---: | ---: | ---: |
| Fusion on (default) | 66,652 | 66,652 | 0 |
| Fusion off (`-Devm-enable-fusion=false`) | 66,652 | 66,652 | 0 |

- Forks: all 14 mainnet hardforks, Frontier through Osaka, every fork at 100.00%.
- 16,907 Amsterdam cases are skipped because Guillotine does not support that
  fork yet.
- Crashes: 0.

Every case passed in both runs. `specs/README.md` explains how to fetch the

### Lean 4 differential fuzzing: 116,384 / 116,384 (100.00%)

`zig build test-lean-diff` generates inputs, runs them through Guillotine and
through a Lean 4.32.0 reference model (`verify/lean`), and compares the results. The
recorded run (default seed, 2,000 iterations per campaign) matched on all
116,384 cases, with zero mismatches and zero crashes, across word operations,
gas and refunds, bytecode analysis, EVM execution, Base/OP Stack rules, and RLP.

### SMT proofs: 32 / 32

`zig build verify-smt` checks the SMT-LIB2 equivalence proofs under
`verify/smt/proofs` (fast paths against reference definitions, for example
`BYTE`, `CLZ`, `EXP` gas and dense jump-table bounds). All 32 theorems are
proved. `zig build verify` runs the LLVM IR, SMT and Lean 4 suites together.

### Legacy filler specs

`zig build specs` runs the older filler-based suite under `specs/cases/`. It
does not pass yet and is not a CI gate. The official state tests above
supersede it.

## Performance

### Apples-to-apples cross-EVM suite (`bench/compare/`)

In-process, differentially verified comparison across 25 canonical workloads
(21 verbatim from `alloy-rs/evm2` + 4 hot loops) on Apple M3 Max (macOS arm64,
Zig `0.17.1`, Rust `1.100.0`, Apple Clang `17.0.0`, Go `1.26.0`, gas on,
tracing off, **100% exact gas + output match across all 12 engine configs**):

| Warm interpreter metric | Guillotine | `evm2` | `revm` | `evmone` (Baseline) | `ethrex` | `gevm` | `geth` |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| **Overall geomean (25 workloads) vs `revm`** | **1.00×** | 1.12× | 1.00× | 0.76× | 0.77× | 0.99× | 0.31× |
| **Classic compute geomean (7) vs `revm`** | **1.43×** | 1.10× | 1.00× | 0.94× | 0.84× | 0.98× | 0.41× |
| `snailtracer` (classic, 205M gas) | **55.53 ms** | 64.75 ms | 81.67 ms | 70.53 ms | 80.80 ms | 92.29 ms | 137.01 ms |
| `burntpix` (mainnet, 92M gas) | **35.42 ms** | 53.65 ms | 65.83 ms | 63.54 ms | 68.33 ms | 77.51 ms | 121.02 ms |
| `uniswap_v3_pool` (mainnet) | **11.40 µs** | 16.71 µs | 19.38 µs | 33.46 µs | 21.73 µs | 22.83 µs | 69.63 µs |
| `fibonacci` (classic) | **17.71 µs** | 51.04 µs | 58.71 µs | 55.67 µs | 58.58 µs | 60.38 µs | 89.88 µs |

Cold first-run analysis (`0.27×` vs `revm`) and pure-Zig `ECRECOVER` (`177.48 µs`
vs ~`30 µs` `libsecp256k1`) remain the primary known bottlenecks. Full warm,
cold, and Tier 2 JIT (`evm2-jit`, `revmc`) tables live in
[Benchmarks and native JIT](/guides/benchmarks-and-jit) and
`bench/compare/RESULTS.md`.

## Checks

### CI

`.github/workflows/ci.yml` runs on every push and pull request:

| Job | What it runs |
| --- | --- |
| `ast-check` | `zig ast-check` on every tracked `*.zig` file |
| `build-test` (macOS arm64, Ubuntu x86_64) | `cargo test --locked`, `zig build`, `test-unit`, `test-opcodes`, `test-modexp`, `test-precompiles`, `test-layer2`, `test-bench`, `test-fusions`, `shared static -Doptimize=ReleaseFast`, the C SDK tests and the TypeScript SDK tests. Linux also runs `test-integration` and a 5-second `fuzz-campaign`; macOS arm64 also runs `test-jit`. |
| `state-tests` (fusion on, fusion off) | `zig build state-tests -Doptimize=ReleaseSafe`, then asserts 66,652 of 66,652 cases passed |

`.github/workflows/fuzz.yml` runs the Zig fuzz targets, a multi-threaded fuzz
campaign, the Rust BN254/BLS12-381 FFI fuzz tests, and the TypeScript SDK fuzz
suite, nightly and on pull requests. `.github/workflows/release.yml` builds and
publishes a release when a `v*` tag is pushed. See
[Publishing and releases](/guides/publishing).

## Feature support

| Area | State |
| --- | --- |
| Ethereum mainnet | Frontier through Osaka |
| Base L2 / OP Stack | Bedrock through Jovian (pre-Azul). `src/layer2/` implements fee, deposit and precompile rules and a transaction executor; `src/layer2/evm_host.zig` runs it on the real `Evm` engine (the type behind `DefaultEvm`), one comptime instance per OP Stack spec. `zig build test-layer2` tests it. |
| Arbitrum Nitro | Not implemented yet. |
| Hardforks | `Hardfork` spans `FRONTIER` through `AMSTERDAM`; the default is `OSAKA`. `state-tests` covers Frontier through Osaka. |
| Precompiles | `0x01`–`0x11` and `P256VERIFY` (`0x100`, Osaka) in `lib/voltaire/src/precompiles/` |
| Zig package | Public modules `evm`, `voltaire` and `layer2` (`dep.module("evm")`) |
| C ABI | Beta (`sdks/c/`, `src/evm_c_api.zig`). Releases ship `libguillotine_ffi.so` (x86_64, glibc >= 2.28), `libguillotine_ffi.dylib` (arm64), `guillotine.h` and `SHA256SUMS.txt`. |
| TypeScript (`@tevm/guillotine`) | Beta; Bun only, over the native library; 340 / 340 tests pass. Prebuilds for `darwin-arm64` and `linux-x64`. |
| WASM | No root build step for the `src/` engine. The separate [`evmts/guillotine-mini`](https://github.com/evmts/guillotine-mini) repository has a WASM build. |
