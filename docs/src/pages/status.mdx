# Project status

Guillotine is **early alpha**. The repository's own words: *do not use in
production*. Any use should be considered purely experimental.

This page records measured results. Each number names its source.

## Ethereum spec compliance

### EEST state tests

`zig build state-tests` runs the official pre-filled Ethereum Execution Spec
Tests against the `src/` engine.

{/* EEST_RESULTS_START — update this block when new EEST runs land */}

Baseline from `specs/README.md` (2026-11-22, `tests@v21.0.3`, ReleaseFast):

- **66,652** cases executed, Frontier through Osaka
- **12,500 passing** (18.75%)
- **54,152 failing**
- 16,907 Amsterdam posts skipped

| Failure reason | Cases |
| --- | ---: |
| `gas_used_mismatch` | 40,684 |
| `status_mismatch` | 13,046 |
| `crash` | 266 |
| `nonce_mismatch` | 125 |
| `storage_mismatch` | 29 |
| `balance_mismatch` | 2 |

Per-fork pass rates run from 9.95% (Istanbul) to 24.35% (SpuriousDragon).
`specs/README.md` has the per-fork table and how to fetch the fixtures.

:::danger
An 18.75% pass rate on the official state tests means Guillotine gets most
cases wrong today. Do not use it to compute anything you rely on (balances, gas
estimates, state roots) without cross-checking against a mature implementation.
:::

{/* EEST_RESULTS_END */}

### Legacy filler & Prague specs

`zig build specs` runs the legacy filler suite plus the checked-in Prague EEST cases:

- **2,213 / 2,251 passing (98.31%)**, **38 failing** (down from 1,031 failures → 581 → 38)
- **100% of checked-in `eest/prague` cases passing** (0 failures)
- The remaining 38 failures are legacy filler-format limitations in `specs/runner.zig` / `specs/lll.zig` (`:yul` compiler not integrated, `lllc`-specific `CREATE2` initcode hashes, and extended LLL macros) rather than core EVM failures.

### TypeScript SDK (`@tevm/guillotine`)

- **321 / 321 passing** (`bun test`, 30,165 assertions across 15 files including live Bun FFI fuzzing)
- `bun run build`, `bun run typecheck`, `publint --strict`, and `attw --pack --profile esm-only` all pass.

### CI

`.github/workflows/ci.yml` runs on `macos-latest` and `ubuntu-latest` with Zig
0.15.2: `zig build`, `zig build test-unit`, `zig build test-opcodes`,
`zig build test-modexp --build-file .smithers/build.zig`, and two Node tests
under `.smithers/tests/`. `.github/workflows/fuzz.yml` runs continuous fuzzing.

### `zig build test-opcodes`

Commit `815ab72f` recorded 756 of 756 `zig build test-opcodes` tests passing
(per-opcode tests plus ModExp, ECRECOVER, and spec-runner unit tests;
`MinimalEvm` differential tests live in `test/differential/` and run via
`zig build test-integration`).

### Benchmarks

Commit `815ab72f` and `78dbd431` verified the 16-suite benchmark harness
(`zig build bench` and `smthrs test //bench:report`), including 42.95 ms
(5.48 Ggas/s) on `snailtracer` under Prague and 4.63x–7.46x geomean speedups
across the Osaka suite. See [Benchmarks and native JIT](/guides/benchmarks-and-jit)
for the full breakdown and methodology.

### Documentation examples

The examples in [Getting started](/getting-started) were compiled and run with
`zig build test-integration` against an earlier tree. See
[Running it](/getting-started#running-it).

### Not re-run during doc builds

- `zig build test` (full specs + integration + unit + lib sweep)
- `zig build state-tests` (official 66k EEST fixtures require fetching the ~900 MB archive via `scripts/fetch-eest-fixtures.sh`)
- `zig build test-lib`

## Feature support

| Area | State |
| --- | --- |
| Ethereum mainnet | The only network `Evm` executes |
| OP Stack (Optimism, Base) | `src/layer2/` implements fee, deposit, and precompile rules as standalone helpers (`zig build test-layer2`). `EvmConfig` cannot select them yet. Planned for beta. |
| Arbitrum Nitro | Not implemented. Planned for beta. |
| Hardforks | `Hardfork` spans `FRONTIER` through `AMSTERDAM`; the default is `OSAKA`. `state-tests` covers Frontier through Osaka. |
| Precompiles | `0x01`–`0x11` and `P256VERIFY` (`0x100`, Osaka) in `lib/voltaire/src/precompiles/` |
| Native JIT | ARM64 tier in `src/jit/`, opt-in through `EvmConfig.enable_native_jit` (default `false`). See [Benchmarks and native JIT](/guides/benchmarks-and-jit#native-arm64-jit). |
| Benchmarks | 16 ReleaseFast suites (`zig build bench`, `smthrs test //bench:report`) with committed baseline in `bench/baseline.json` |
| Formal verification | `zig build verify`: LLVM 20 IR equivalence + Bitwuzla/Z3 SMT + Lean 4 proofs (`verify/`) |
| C ABI | Experimental (`sdks/c/`, `src/evm_c_api.zig`) |
| TypeScript (`@tevm/guillotine`) | Experimental; Bun ≥ 1.1 only, Bun FFI over `libguillotine_ffi` |
| WASM | No root build step for the `src/` engine. For a browser WASM build, use [guillotine-mini](https://github.com/evmts/guillotine-mini). |
