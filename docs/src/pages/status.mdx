# Project status

Guillotine is **early alpha**. The repository's own words: *do not use in
production*. Any use should be considered purely experimental.

This page records measured results. Each number names its source.

## Ethereum spec compliance

### EEST state tests

`zig build state-tests` runs the official pre-filled Ethereum Execution Spec
Tests against the `src/` engine. Baseline from `specs/README.md` (2026-11-22,
`tests@v21.0.3`, ReleaseFast):

- **66,652** cases executed, Frontier through Osaka
- **12,500 passing** (18.75%)
- **54,152 failing**
- 16,907 Amsterdam posts skipped

| Failure reason | Cases |
| --- | ---: |
| `gas_used_mismatch` | 40,684 |
| `status_mismatch` | 13,046 |
| `crash` | 266 |
| `nonce_mismatch` | 125 |
| `storage_mismatch` | 29 |
| `balance_mismatch` | 2 |

Per-fork pass rates run from 9.95% (Istanbul) to 24.35% (SpuriousDragon).
`specs/README.md` has the per-fork table and how to fetch the fixtures.

### Legacy filler specs

`zig build specs` runs the legacy filler suite. Commit `7501b986` recorded 581
failures (down from 1031) with no regressions. The repository README's figure of
1165 passing out of 2251 predates that commit.

:::danger
An 18.75% pass rate on the official state tests means Guillotine gets most
cases wrong today. Do not use it to compute anything you rely on (balances, gas
estimates, state roots) without cross-checking against a mature implementation.
:::

### CI

`.github/workflows/ci.yml` runs on `macos-latest` and `ubuntu-latest` with Zig
0.15.2: `zig build`, `zig build test-unit`, `zig build test-opcodes`,
`zig build test-modexp --build-file .smithers/build.zig`, and two Node tests
under `.smithers/tests/`. `.github/workflows/fuzz.yml` runs continuous fuzzing.

### `zig build test-opcodes`

Commit `815ab72f` recorded 756 of 756 per-opcode differential tests passing.

### Documentation examples

The examples in [Getting started](/getting-started) were compiled and run with
`zig build test-integration` against an earlier tree. See
[Running it](/getting-started#running-it).

### Not run for these docs

- `zig build test` (specs, integration, unit, and lib tests)
- `zig build specs` and `zig build state-tests`
- `zig build test-lib`
- Every `sdks/` build
- Any benchmark

## Feature support

| Area | State |
| --- | --- |
| Ethereum mainnet | The only network `Evm` executes |
| OP Stack (Optimism, Base) | `src/layer2/` implements fee, deposit, and precompile rules as standalone helpers (`zig build test-layer2`). `EvmConfig` cannot select them yet. Planned for beta. |
| Arbitrum Nitro | Not implemented. Planned for beta. |
| Hardforks | `Hardfork` spans `FRONTIER` through `AMSTERDAM`; the default is `OSAKA`. `state-tests` covers Frontier through Osaka. |
| Precompiles | `0x01`–`0x11` and `P256VERIFY` (`0x100`, Osaka) in `lib/voltaire/src/precompiles/` |
| Native JIT | ARM64 tier in `src/jit/`, opt-in through `EvmConfig.enable_native_jit` (default `false`) |
| C ABI | Experimental (`sdks/c/`, `src/evm_c_api.zig`) |
| TypeScript (`@tevm/guillotine`) | Experimental; Bun only, over the native library |
| WASM | No root build step for the `src/` engine. guillotine-mini builds with `cd mini && zig build wasm`. |
