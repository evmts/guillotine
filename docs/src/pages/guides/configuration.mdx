# Configuring the EVM

`Evm` is a function from an `EvmConfig` to a type. Configuration is therefore
free at runtime: unused branches are not compiled, and the compiler can inline
across what remains.

```zig
const Evm = @import("evm").Evm;
const eips = @import("evm").Eips;

const Osaka = Evm(.{}); // the default hardfork

const Small = Evm(.{
    .eips = eips{ .hardfork = .SHANGHAI },
    .enable_precompiles = false,
    .memory_limit = 1 << 20,
});
```

## Every field

Verified against `src/evm_config.zig`.

### Semantics

| Field | Default | Meaning |
| --- | --- | --- |
| `eips` | `Eips{ .hardfork = Hardfork.DEFAULT }` (`OSAKA`) | Which hardfork's rules to implement. `Eips.overrides` turns individual EIPs on or off. |
| `eip_overrides` | `&.{}` | Declared but not read outside `src/evm_config.zig`. Use `eips.overrides`. |
| `max_call_depth` | `1024` | Call-stack depth limit (spec value). |
| `max_bytecode_size` | `24576` | EIP-170 contract size cap. |
| `max_initcode_size` | `49152` | EIP-3860 initcode cap. |
| `max_input_size` | `131072` | Declared but not read outside tests. `CallParams.validate` applies a fixed 4 MiB input cap. |
| `block_gas_limit` | `30_000_000` | Ceiling used for validation. |
| `enable_beacon_roots` | `true` | EIP-4788 beacon-root system call. |
| `enable_historical_block_hashes` | `true` | EIP-2935 historical hashes. |
| `enable_validator_deposits` | `true` | Deposit-contract system processing. |
| `enable_validator_withdrawals` | `true` | Withdrawal processing. |

### Performance

| Field | Default | Meaning |
| --- | --- | --- |
| `enable_fusion` | `true` | Opcode fusion. See [Synthetic opcodes](/concepts/synthetic-opcodes). |
| `enable_native_jit` | `false` | Run hot, eligible pure-compute contracts through the ARM64 JIT tier in `src/jit/`. Other targets, traced runs, and initcode use the interpreter. |
| `enable_precompiles` | `true` | When `false`, calls to precompile addresses skip the precompile path. |
| `vector_length` | `0` | SIMD width; `0` auto-detects for the target. |
| `stack_size` | `1024` | Stack slots. Smaller stacks shrink the frame. |
| `memory_initial_capacity` | `4096` | Bytes pre-allocated per frame's memory. |
| `memory_limit` | `0xFFFFFF` | 16 MiB per-frame memory ceiling. |
| `arena_capacity_limit` | `64 * 1024 * 1024` | Per-call scratch arena ceiling. |
| `arena_growth_factor` | `150` | Arena growth, as a percentage. |
| `loop_quota` | `1_000_000` in Debug/ReleaseSafe, `null` otherwise | Analysis-loop safety bound. |
| `WordType` | `u256` | EVM word type. |

### Testing escape hatches

| Field | Default | Meaning |
| --- | --- | --- |
| `disable_gas_checks` | `false` | Execute without metering gas. |
| `disable_balance_checks` | `false` | Skip balance sufficiency checks. |

:::danger
`disable_gas_checks` and `disable_balance_checks` produce a machine that is **not
an EVM**. They exist for fuzzing and for isolating a stack/memory bug from a gas
bug. Never ship them.
:::

### Extension points

| Field | Default | Meaning |
| --- | --- | --- |
| `DatabaseType` | `Database` (`src/storage/database.zig`) | State backend type. |
| `opcode_overrides` | `&.{}` | Declared but not applied: `frame_config()` passes `&.{}` and `Frame` builds its handler table with `getOpcodeHandlers(Self, &.{})` (`src/frame/frame.zig`). |
| `precompile_overrides` | `&.{}` | Declared but not read outside `src/evm_config.zig`. |
| `block_info_config` | `.{ .DifficultyType = u64, .BaseFeeType = u64, .use_compact_types = false }` | Compact vs full block-info field widths. |
| `tracer_config` | `TracerConfig.disabled` | See [Tracing](/guides/tracing). |

## Recipes

### The default mainnet EVM

```zig
const Mainnet = @import("evm").Evm(.{});
// Or use the pre-instantiated alias:
const Mainnet2 = @import("evm").MainnetEvm;
```

### A small-footprint EVM

Turn off precompiles and shrink the memory ceilings:

```zig
const Tiny = @import("evm").Evm(.{
    .enable_precompiles = false,
    .memory_limit = 1 << 18,
    .memory_initial_capacity = 512,
    .arena_capacity_limit = 1 << 20,
});
```

The root build has no WASM step for the `src/` engine. See
[Language bindings](/guides/bindings#wasm).

### A historical-fork EVM

```zig
const eips = @import("evm").Eips;
const Frontier = @import("evm").Evm(.{ .eips = eips{ .hardfork = .FRONTIER } });
const London   = @import("evm").Evm(.{ .eips = eips{ .hardfork = .LONDON } });
```

`Eips` accepts every `Hardfork` variant, `FRONTIER` through `AMSTERDAM`. See
[Hardforks and EIPs](/reference/hardforks).

### A fuzzing EVM

```zig
const Fuzz = @import("evm").Evm(.{
    .disable_gas_checks = true,
    .disable_balance_checks = true,
    .enable_fusion = false,   // fewer variables while triaging
});
```

### Overriding an opcode or a precompile

`EvmConfig` declares `opcode_overrides` and `precompile_overrides`, but nothing
applies them yet. `frame_config()` passes `&.{}` for opcode overrides,
`Frame` builds its handler table with `getOpcodeHandlers(Self, &.{})`, and
nothing outside `src/evm_config.zig` reads `precompile_overrides`. Setting
either field compiles and changes nothing.

## Build flags do not configure the engine

`build.zig` declares `-Devm-hardfork`, `-Devm-enable-fusion`,
`-Devm-disable-gas`, `-Devm-optimize`, `-Dmax-call-depth`, and related flags
(`zig build -h`). The `src/` engine reads only `enable_tracing` from the
generated `build_options` module (`src/instructions/handlers_jump.zig`).
`BuildConfiguredEvm` and `DefaultEvm` are `Evm(EvmConfig{})` (`src/root.zig`),
so they use the defaults above whatever flags you pass. Set `EvmConfig` fields
in Zig instead.
