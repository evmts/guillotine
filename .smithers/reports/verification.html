Archive diagnosis

Issue #815 shows a Rust archive stored as an archive member where LLD expects ELF objects or LLVM bitcode. In lib/foundry.zig, the Linux wrapper now sets use_lld = false, selecting Zig 0.15.1’s native ELF archiver, which merges object members. The legacy lib/foundry-compilers/rust_build.zig was inspected; the active root build uses lib/foundry.zig.

Workspace discovery and targets

The needlefish reference was inspected. The requested ~/voltaire-factory/.smithers directory was absent; the current local Smithers source and its own factory were used to verify formats. This CLI discovers .smithers/WORKSPACE.ts and PACKAGE.ts, not WORKSPACE.smithers. The latter is a compatibility re-export. A root-anchored Filegroup and a separate factory group are necessary because globs remain package-scoped even with a // prefix.

The root build has no test-modexp or benchmark step. Both are implemented in the supplemental .smithers/build.zig, without changing root build files. MODEXP uses all 43 existing repository tests, including failures. Benchmark compilation is cached; timing runs are fresh and validate their result. This workload measures MODEXP arithmetic, not overall EVM performance.
